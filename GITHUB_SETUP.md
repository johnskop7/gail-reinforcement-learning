## Upload

Create a new empty repository with this name and your chosen visibility. Extract the package and upload its contents so the main README, `expert_policies/`, `imitation_learning/`, and `docs/` appear directly at the repository root. Upload the files, not the ZIP container.

For Git, open a terminal in the extracted folder:

```bash
git init
git add .
git commit -m "Organize GAIL and reinforcement learning semester project"
git branch -M main
```

Then copy the exact remote URL and push instructions from the new GitHub repository. Add the description and topics in the About settings. This package does not itself publish a live repository.
