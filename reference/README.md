# Reference and historical material

- `gail-baseline/`: the supplied earlier GAIL tree, including its original README, license, source, assets, checkpoints, and expert files. Historical Windows paths remain unchanged here.
- `original-scripts/`: byte-for-byte originals of the active scripts adjusted during repository organization.
- `standalone-validation/`: the original isolated validation experiment, whose `models` import assumes a GAIL source context.

Use the top-level README and active directories for execution instructions. The baseline README's root-relative figure paths belong to its original repository layout. Its figures are available under `gail-baseline/assets/img/README/`.
